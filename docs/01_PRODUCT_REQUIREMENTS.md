# 01 — 产品需求与范围

## 1. 产品愿景
把教师的原始化学资料转化为高质量、可追溯、可编辑的教学内容。产品价值不是“生成更多页面”，而是降低教师整理资料、设计教学路径、绘制准确化学图解、编写练习与检查错误的成本。

## 2. 用户与权限
### MVP
- 单教师账户；教师拥有所有项目、文件、讲义和审核操作。
- 可预留管理员角色，但不实现复杂组织/班级权限。
- 后端所有资源仍必须有 owner_id，防止未来多用户时数据模型返工。

### 后续
- 多教师工作空间、协作者、只读审阅者、学生只读访问。
- 组织级模板和共享题库。
这些不属于 MVP 验收范围。

## 3. 核心用户旅程
1. 创建课程项目：名称、课程/考试体系、年级/Level、语言、目标学生。
2. 建立资料库：上传历年真题 PDF、教材、考纲和教师材料。
3. 解析资料：展示解析状态、页数、页面缩略图、文本/表格/图片抽取结果。
4. 校对：教师可修正标题、页码、题号、知识点标签和 OCR 错误。
5. 知识点整理：建立主题树、考点、先修关系、易错点。
6. 讲义规划：教师选知识点或资料范围，系统给出教学目标、页面功能和大纲。
7. 确认大纲：教师编辑、排序、删除或增加单元。
8. 生成内容：按 section 分别生成，允许重试单节，不重做全部讲义。
9. 审核：化学结构、答案推导、教学逻辑、图形、来源和语言质量。
10. 编辑：富文本/块编辑，保留原始生成版本；可对选区提出修改指令。
11. 预览导出：浏览器预览、PDF 导出、下载和版本回滚。

## 4. 功能需求

### FR-01 项目管理（P0）
- 创建、重命名、归档、删除项目（删除需二次确认）。
- 项目列表展示最近活动、资料数量、讲义数量、当前状态。
- 项目设置包括课程体系、目标考试、Level、默认语言和视觉主题。
- 项目删除采用软删除；后台提供可恢复窗口，具体保留期由部署配置决定。

### FR-02 文件管理（P0）
- 支持 PDF 首发；文件类型白名单、大小上限、SHA-256、重复文件识别。
- 原文件不可被解析结果覆盖。
- 上传后进入异步解析任务。
- 支持解析失败重试、取消、删除和重新解析。
- 页面级信息必须保留原 PDF 页码；图片裁剪区域可关联页码和 bbox。
- UI 展示解析质量和需要人工检查的页面。
- DOCX、PPTX、扫描件 OCR 深度优化列为后续能力；PDF 图片/扫描页应有 OCR fallback。

### FR-03 解析与来源定位（P0）
- 提取文本、标题、段落、表格、图片、公式候选、页面尺寸和页码。
- 每个 chunk 保留 document_id、page_number、bbox（若可用）、parser_version。
- OCR/公式识别不确定时标注 confidence/status，不静默猜测。
- 解析后提供页面预览和原文定位。
- 解析产物可重新生成且版本化。

### FR-04 知识库（P0）
- 知识点支持名称、定义、课程标签、难度、先修关系、常见误区、来源。
- 支持教师手工创建、编辑、合并、归档。
- 从资料自动抽取的知识点必须经教师确认后成为正式条目。
- 检索同时支持关键词和语义向量；第一版可先实现 PostgreSQL FTS，向量能力按评测结果启用。
- 检索结果必须返回来源片段和页码，不允许只有无来源答案。

### FR-05 题目管理（P0）
- Question 必须有 source_type：past_paper、adapted、original、teacher_authored、unknown。
- 保存题干、选项、答案、评分点、图表/结构图引用、考试体系、年份、试卷编号、题号、页码。
- 真题来源字段缺失时标记 unknown，不能推断为 past_paper。
- 支持教师确认/修订抽取题目。
- 支持题目与知识点多对多关联。

### FR-06 教学规划（P0）
- 规划前先输出教学目标、考点拆解、先修知识、难度、常见误区和学生预期能力。
- 根据知识复杂度动态决定 section 数量和页面功能，不预设每个知识点固定页数。
- 支持页面功能类型：Visual Explanation、Worked Example、Student Practice、Answers & Pitfalls、Summary/Reference。
- 大纲可编辑、排序、确认；未确认不能启动正式批量生成。
- 生成大纲应显示每个 section 的学习目标、核心概念、所需图示、练习和来源。

### FR-07 讲义生成（P0）
- 按 section 生成结构化内容，不直接生成最终 PDF。
- 内容包含标题、教学解释、图示规格、例题、分步解答、评分点、陷阱、练习、答案和来源。
- 允许单节重生成、局部修改、版本比较和回滚。
- 所有题目标记来源类型。
- 输出需符合内容 Schema；不符合时拒绝进入渲染。
- 中英双语策略按项目设置，默认英文为主、中文辅助。

### FR-08 化学结构与图解（P0 核心）
- 结构内容以 ChemSpec 表达；具体规范见 docs/07。
- 支持 2D 结构、弯箭头、Lewis structures、共振 contributors/杂化体、形式/部分电荷、轨道/电子云示意。
- 立体内容支持明确的 3D 数据来源和球棍可视化；不得把 2D 示意伪装成真实 3D。
- 图示必须完整表达题目所需的原子、键、取代基、隐含氢和空间关系。
- 自动结构检查失败或结构存在歧义时，阻断发布并要求修正/人工确认。
- 任何模型生成的 SMILES/MolBlock 都必须经过解析、价态、形式电荷和立体检查。

### FR-09 审核与质量门禁（P0）
- 化学事实、结构、推导、教学逻辑、题目答案、图形视觉、来源引用、语言排版分开评分。
- 硬性错误不得被平均分掩盖。
- Reviewer A/B 可独立审查，输入隔离，结论后才做差异分析。
- 争议项进入人工复核。
- 未通过硬门禁不得导出为正式版本。
- 详细规则见 docs/08。

### FR-10 编辑器与导出（P0）
- 支持 section 级编辑、块级重排、图片替换、标题/正文/公式/题目/提示块。
- 编辑操作形成新版本或可恢复历史，不直接覆盖原始生成快照。
- HTML 预览与 PDF 输出使用同一套设计 token 和组件。
- PDF 导出需检查字体嵌入、分页、图像清晰度、公式溢出和空白页。
- 讲义支持导出单节和整份。

### FR-11 模板（P1）
- 内置柔和明亮的教学模板；允许调整配色、字体、页眉页脚、标签和页面组件。
- 模板与内容数据分离；模板升级不得破坏历史讲义。
- 主题风格参考：柔和粉/紫/浅蓝/黄/绿、深蓝标题、圆角分区、实验室卡通图标、充足行距。
- 不允许将模板装饰优先于化学可读性。

### FR-12 对话助手（P1）
- 可在项目上下文内问答、讨论知识点、修改讲义。
- 回答引用项目资料和页码。
- 修改讲义时必须说明目标 section 和变更范围。
- 不允许聊天模型绕过工作流直接写入已发布版本。

## 5. 非功能需求
- 可恢复：异步任务有状态、进度、错误码、重试和取消。
- 可追溯：文件、解析、知识、题目、生成、审核、导出全链路可关联。
- 安全：文件校验、权限检查、密钥不入库、上传隔离。
- 可测试：核心规则可用固定 fixture 测试；关键 UI 可 E2E。
- 可观测：记录耗时、模型调用、token、失败原因、节点重试次数。
- 可扩展：模块边界清楚，但 MVP 避免过度微服务化。

## 6. MVP 明确不做
- 学生端账号和在线考试系统。
- 公开题库市场、支付订阅、积分体系。
- 实时多人协作编辑。
- 自动发布到 LMS。
- 自动保证所有化学图像百分之百正确；系统必须提供验证和人工确认机制，而不是虚假承诺。
- 未经授权的整本教材分发或公共分享。

## 7. 产品成功指标（初期观测）
- PDF 解析成功率及人工修正率。
- 题目来源定位准确率。
- ChemSpec 结构校验通过率和人工推翻率。
- 讲义审核硬错误数量。
- 每份讲义教师编辑时间。
- PDF 导出成功率、返工率。
- 学生练习正确率/迁移题表现（需教师提供反馈数据，不能仅用模型自评）。
