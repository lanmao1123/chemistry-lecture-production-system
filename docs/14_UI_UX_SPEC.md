# 14 — UI / UX 与视觉规范

## 1. 设计目标
这是教师生产工具，不是学生题库或 LMS。界面优先展示当前任务、资料、讲义内容和可执行操作。减少装饰性 Dashboard、复杂统计卡片和不必要导航。

## 2. 信息架构
主导航：
- 工作台
- 课程项目
- 资料库
- 知识点与题目
- 讲义
- 模板（P1）
- 设置

进入项目后使用项目级二级导航：概览、资料、知识点、讲义生产、审核、导出。

## 3. 核心页面
### 工作台
展示最近项目、正在解析/生成的任务、待教师确认事项、最近编辑的讲义。避免堆砌无意义图表。

### 项目详情
显示项目基本信息、资料数量、讲义状态和最近活动；提供明确的“上传资料”和“新建讲义”入口。

### 资料库
左侧文件列表/分类，主区显示 PDF 页面预览，右侧显示抽取文本、题目和知识点。点击引用可定位原页和 bbox。解析状态、低置信提示和失败原因要清楚。

### 讲义生产
采用分步工作区：目标与范围 → 资料选择 → 教学大纲 → 分节生成 → 审核 → 编辑/导出。顶部显示当前阶段与状态，不要一次展示所有复杂设置。

### 讲义编辑器
左侧 section 大纲，中间内容编辑/预览，右侧上下文、来源引用和审核 findings。支持选中内容修改、版本比较、恢复。关键化学图可打开大尺寸/3D 视图。

### 审核中心
按 BLOCKER/MAJOR/MINOR 分组；点击 finding 能定位到 section、文字或结构图；展示 reviewer 证据、规则 ID、修复建议和人工处理按钮。

## 4. 视觉方向
- 明亮柔和的粉、紫、浅蓝、黄、绿作为辅助色。
- 深蓝作为标题和主要文字色。
- 圆角卡片/分区，少量卡通实验室图标作为品牌点缀。
- 页面背景保持浅色和低干扰；避免大面积高饱和渐变。
- 视觉层级清楚，内容密度适中。
- 英文为主，中文辅助；英文正文视觉字号应大于中文辅助说明。
- 中英混排行距充足；公式和结构图不得被压缩。
- 3A/3B 等标签在所有页面统一位置、大小和颜色规则。
- 图形必须优先可读性和科学准确性，装饰不得遮挡信息。

## 5. 响应式
桌面端优先（教师主要进行资料整理和编辑）；平板可查看和轻量编辑；手机优先支持查看任务状态和讲义，不要求完整复杂编辑器体验。

## 6. 状态设计
每个异步区域都必须有 loading、empty、success、warning、error、retry 状态。任务运行时显示步骤和进度；失败时显示错误原因、可重试与否。等待人工确认时给出明确下一步。

## 7. 可访问性
键盘可操作、焦点状态清晰、颜色不是唯一状态表达、文字对比度符合 WCAG AA 目标、图像提供替代文本。化学图应提供结构摘要或可访问描述。

## 8. 前端组件
建立 Design Tokens：color、typography、spacing、radius、shadow、z-index。基础组件统一 Button、Dialog、Tabs、Badge、Alert、Progress、DataTable、FileUploader、PDFViewer、SourceCitation、ChemistryCanvas、ReviewFinding、SectionOutline。
