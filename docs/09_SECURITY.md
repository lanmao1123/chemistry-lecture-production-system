# 09 — 安全、隐私与版权

## 1. 威胁模型
保护教师账户、上传文件、题目/教材内容、API key、生成结果和审核记录。主要风险：恶意文件、解析器漏洞、越权访问、对象存储泄漏、提示词注入、模型数据外泄、XSS、CSRF、SSRF、资源耗尽和版权违规。

## 2. 身份与授权
- 密码使用 Argon2id 或经过审查的身份提供商。
- Cookie session 使用 HttpOnly、Secure、SameSite；写请求做 CSRF 防护。
- 所有 API 做资源级 owner/project 授权。
- 不信任前端传来的 owner_id。
- 管理操作写 audit event。
- 登录、上传、模型生成、导出均限流。

## 3. 文件安全
- 只允许白名单 MIME 和扩展名组合；不能只信任扩展名。
- 检查文件 magic bytes、大小、页数、解压/解析资源限制。
- PDF 在隔离 Worker 处理；设置 CPU、内存、时间和临时磁盘上限。
- 不允许解析器访问任意内网地址。
- 原文件存私有 bucket；下载用短时签名 URL。
- 文件名做规范化，禁止路径穿越。
- 生产环境接入恶意文件扫描能力前，上传状态标记 pending_scan，不可直接发布。

## 4. Prompt injection 与 RAG
上传资料中的文本是数据，不是系统指令。
- 检索片段明确包裹为 untrusted source。
- Agent 不执行资料中要求泄漏密钥、访问 URL、删除文件或改变系统规则的指令。
- 模型工具使用 allowlist；工具权限由服务端控制。
- 模型不直接获得数据库凭证或对象存储管理员凭证。
- 对输出做 schema、权限和业务规则校验。

## 5. 密钥
- API keys 仅放环境变量或 Secret Manager。
- .env 必须 gitignore；提供 .env.example 且只有占位符。
- 日志和错误信息必须脱敏。
- 定期轮换；泄漏后立即撤销。
- 不在 prompt、前端 bundle、source map 或客户端日志暴露密钥。

## 6. Web 安全
- React 默认 escaping；富文本 HTML 使用严格 sanitizer。
- SVG 作为不可信内容时清理 script、事件属性、外部链接和危险元素。
- CSP、HSTS、X-Content-Type-Options、Referrer-Policy。
- SSRF：禁止任意 URL fetch；如确需 URL 导入，限制协议、DNS/IP 范围并防重绑定。
- CORS 只允许配置的前端域名。
- SQL 使用参数化 ORM/query。
- 依赖漏洞扫描和 secret scanning 加入 CI。

## 7. 版权与来源
- 资料库默认私有。
- 教师必须确认拥有上传和使用资料的权利。
- 不默认提供整本教材公开分享。
- 讲义中保留原始来源和题目出处。
- 对受版权保护的原文采用必要引用和教师授权范围，不批量输出替代原书的内容。
- 导出文件可附来源清单；公开分享功能需另做版权评估。

## 8. 隐私与数据生命周期
- 收集最少个人信息。
- 明确模型供应商是否保存请求/用于训练及数据区域；供应商条款不明时禁止发送敏感资料。
- 支持账户/项目/文件删除流程；备份中的数据按保留策略过期。
- 审计日志避免保存完整题目正文或密钥。
- 正式上线前由负责人确认隐私政策、服务条款和数据处理协议。

## 9. 安全验收
覆盖 IDOR、CSRF、XSS、恶意 PDF、超大文件、路径穿越、SVG script、提示词注入、速率限制、签名 URL 过期、密钥扫描和备份恢复。
