# 15 — 风险登记与待决策项

## 1. 已确认方向
- 面向国际化学教师的讲义生产 Web 产品。
- MVP 单教师使用，但数据模型保留 owner/project 维度。
- 从 PDF 真题批量整理开始。
- Agent 采用 LangGraph 有状态编排。
- 化学结构与图形质量是核心，不允许纯文本 LLM 直接决定正确性。
- 以学生能否独立解题并获得分数为最终教学目标。
- 讲义风格采用明亮柔和配色、圆角分区、深蓝标题、英文为主的双语版式。

## 2. 推荐但待 ADR 确认
- Next.js + FastAPI + PostgreSQL + Redis。
- Docker Compose 单体部署。
- Docling 作为首选 PDF 解析器。
- RDKit 为主要分子结构工具，Indigo 作为补充评估。
- Playwright 作为 PDF 输出。
- 采用对象存储保存原文件和产物。
- 独立 Reviewer A/B 审核。

## 3. 必须通过 PoC 的风险
R1 PDF 化学图像提取：普通 OCR 可能无法准确识别结构式、曲线、表格和公式。需要用真实代表性 PDF 测试；失败时保留页面截图和人工标注入口。

R2 题目切分：题目可能跨页，图和题干可能分离。必须通过页码、题号、版面结构和人工校对处理。

R3 化学结构生成：SMILES 不足以表达教学图中的箭头、电子云、共振杂化体、对称面等。ChemSpec 必须支持教学层注释，复杂类型允许人工绘制/确认。

R4 3D 几何：计算构象不是唯一真实构象；模型生成的坐标不一定具有实验意义。UI 和 PDF 必须标注示意/计算构象。

R5 教学质量评估：LLM 自评可能偏差。需要教师标注的评测集和学生答题反馈。

R6 PDF 排版：浏览器打印可能出现字体替换、公式截断、分页异常。需固定字体和 Chromium 版本并做视觉回归。

R7 模型供应商：隐私、价格、速率限制和输出稳定性变化。通过 ModelGateway 隔离供应商。

R8 版权：教师资料不意味着可以公开分发。默认私有，保留来源并由教师确认使用权。

## 4. Open questions（负责人确认）
1. 首发考试体系：UKCHO、A-Level、IB、其他？可先支持项目配置，但 rubric 和题目字段需按首发体系校准。
2. 首发语言：是否默认英文为主、中文辅助？目前按此作为默认假设。
3. 账号登录：邮箱密码、Google OAuth，还是先使用单管理员账号？需选型。
4. 模型供应商和主模型：需确认 API、预算、数据使用政策和区域。
5. PDF 最大文件大小/页数与 OCR 预算。
6. 是否首发即需要可旋转 3D 模型，还是先实现 2D + 3D PoC 后决定范围。
7. 富文本编辑器选择 TipTap 或 Lexical。
8. 队列选择 Celery 或 ARQ。
9. 生产部署平台、域名、对象存储和备份 RPO/RTO。
10. 用户是否需要视频讲解/结构旋转动画；当前列为后续，不阻塞 MVP。

## 5. 风险处置规则
- Open question 不得由 Agent 自行选择影响架构的答案。
- 可以在不影响架构的前提下用配置/接口预留。
- PoC 结果必须有测试数据、限制和结论。
- 影响已确认决策时创建 ADR，等待负责人批准。
