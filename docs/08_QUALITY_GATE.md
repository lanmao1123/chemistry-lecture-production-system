# 08 — 质量门禁与审核体系

## 1. 质量不是单一总分
至少分为六个维度：化学事实、结构/机理、答案与评分点、教学设计、图形/排版、来源与引用。每个维度单独记录状态和证据。严重硬错误不能被其他维度高分抵消。

## 2. 严重级别
- BLOCKER：化学结构错误、答案错误、关键机理错误、来源伪造、图示与解释相反、关键步骤缺失。
- MAJOR：重要教学逻辑断裂、评分点遗漏、图形关键信息遮挡、题目条件遗漏。
- MINOR：非关键措辞、轻微排版、非核心标注问题。
- SUGGESTION：可读性或教学增强建议。

BLOCKER 必须修复并重新验证；MAJOR 由教师决定是否阻断；MINOR 可记录后处理；SUGGESTION 不阻断。

## 3. 审核维度与检查项
### 化学事实
- 元素、分子式、结构连接、键级、形式电荷、氢数。
- 反应物/产物、反应条件、机理箭头。
- 立体化学和空间构型。
- 命名、酸碱性、电子效应、共振等解释。
### 答案与评分
- 是否回答题目全部要求。
- 计算步骤、单位、有效数字。
- mark scheme 关键点是否覆盖。
- 结论是否能由展示的推理推出。
### 教学设计
- 目标是否可测量。
- 先修知识是否足够。
- 是否解释 why/how，而非只有结论。
- 是否提供从基础例题到陌生迁移题的梯度。
- 是否针对常见误区设置陷阱提示。
### 图形
- 原子/键/箭头/标签完整。
- 3D 与 2D 表达没有混淆。
- 结构图与文字一致。
- 无遮挡、裁切、低分辨率和错误字体。
### 来源
- 真题、改编题、原创题标签准确。
- 页码、题号、来源文档有效。
- 引用片段确实支持该结论。
- 不存在虚构年份、考试局或评分标准。
### 语言与排版
- 英文术语准确。
- 中英内容一致。
- 英文为主且字号更大。
- 标签位置统一、行距充分、页面层级清楚。

## 4. 独立盲审
Reviewer A 负责化学事实、推导和评分点；Reviewer B 负责教学清晰度、图形与来源一致性。角色可按任务调整，但必须在执行前冻结各自 rubric。
- 两个 reviewer 分别获得相同必要事实材料，不共享彼此输出。
- 先保存两份原始结果和输入 hash。
- 后续比较器分析共识、分歧和单方发现。
- reviewer 不得仅因为另一个 reviewer 认为正确就改变独立判断。
- 争议项必须人工决策或通过明确规则裁定。

## 5. 自动修复控制
- 自动修复最多 2 轮。
- 每轮只处理当前未解决的 findings。
- 用 finding fingerprint 去重。
- 修复只允许触及指定 section/block/ChemSpec。
- 修复后重新执行受影响的所有 validator 和必要回归。
- 超过上限、出现新 BLOCKER 或结果振荡时暂停并请求教师处理。
- 不允许通过降低评分标准、删除 finding 或修改测试预期来“通过”。

## 6. 发布门禁
Approved 必须同时满足：
1. Schema validation pass。
2. 所有 BLOCKER findings resolved。
3. required chemistry validators pass 或明确人工签署 override。
4. 所有引用可解析。
5. PDF/HTML 渲染检查通过。
6. 人工批准记录对应准确 revision。
7. 导出使用的模板和内容版本已冻结。
任何 override 必须记录人员、理由、时间和风险。

## 7. 教师反馈闭环
教师可对审核项标记正确/误报/需修改，并说明原因。反馈进入评测集候选池；不能直接自动修改规则。每次规则更新先在固定回归集上评估误报/漏报。
